- Added Gnani Vachana speech AI services (`pipecat.services.gnani`). Provides `GnaniSTTService` for WebSocket-based real-time speech-to-text, `GnaniHttpTTSService` for REST-based text-to-speech, and `GnaniTTSService` for WebSocket-based streaming TTS with interruption handling. Supports 10 Indian languages and 8 voice options via the Vachana platform. Install with `pip install pipecat-ai[gnani]` or standalone via `pip install pipecat-gnani`.
